JSUI 0.12.0 is a features release. Hosts can now register their own Skia-drawing components, a JSUI app can embed other JSUI apps, text can be selected and copied, and on the web JSUI can share the page's WebGPU device with a 3D engine. Touch scrolling is smoother, and safe areas are handled everywhere.

## Highlights

- **Native components**: hosts register view classes that draw straight into JSUI's Skia canvas (C `jsui_register_component`, C++ `jsui::Component`, web `jsui.registerComponent`), used from React with `requireNativeComponent`, with props, animated props, commands and events. See docs/NATIVE_COMPONENTS.md and the new /features/native page (#211).
- **JSUIContainer**: `<JSUIContainer bundleSrc>` runs another JSUI bundle in an isolated child runtime inside a view, with messages, calls and shared state both ways (#206). Children inherit the parent's fonts, textures, audio, video and loaders by default; the `services` prop and the `JsuiConfig.on_child` hook override or deny them per container (#208).
- **Shared WebGPU device on the web**: `createJsui({ device })` runs JSUI on the page's own `GPUDevice`, `jsui.createTextureSurface()` renders a UI into a `GPUTexture` for a game to sample (with input forwarding), and `setTexture(name, gpuTexture)` shows a game texture in the UI with zero copies. New Three.js example at /three/ (#209).
- **Selectable text**: `<Text selectable>` with mouse and keyboard selection, long-press on touch, and copy; the web host now uses the system clipboard for copy and paste, including in TextInput (#210).
- **Safe-area insets** on every host, and an iOS status bar API (`StatusBar`) (#205).

## Input

- **Smoother touch scrolling**: drag events are resampled to the frame clock, the drag no longer jumps by the touch slop when it starts, fling velocity uses a least-squares fit, and iOS and Android drive frames from the display's vsync clock (#202).

## Platforms

- **iOS**: sound and video playback, and portrait orientation (#201, #202).

## Fixes

- **Safari WebGPU**: WebKit (Safari 26 on macOS and iOS) rejects render pipelines with f16 fragment outputs, which blanked JSUI when the page's device had `shader-f16` enabled (as Three.js requests). JSUI now probes for this once and hides the feature from Skia when needed (#213).
- LayoutAnimation no longer treats nodes whose layout was reset as new (#200).

## Site and docs

- The showcase is split into Use cases, Examples and Features sections, with full-screen examples (#203); the README gained a "Why?" section (#204).

JSUI 0.9.0 makes web deploys one command with WebGPU included, brings the Godot integration to godot-aw3's threaded web export, keeps Vulkan pipelines across launches, and documents what JSUI costs a game in a new [docs/PERFORMANCE.md](https://github.com/orktes/jsui/blob/main/docs/PERFORMANCE.md).

## Highlights

- **`jsui build --web <dir>`** writes a deployable static site: the bundle, the host scripts, all three WASM builds (WebGPU, WebGL, CPU) and an `index.html`, every URL content-hashed (#136). No more copying `jsui-web.js` and `dist*/` out of `node_modules` by hand, and no more silently losing WebGPU by deploying only `dist-webgl/`. The deployed `jsui-web.js` knows its module versions, so custom pages need no `moduleVersions`; later builds keep an edited `index.html` and update its URLs, and `--html` uses your own page. The bundle defaults to `--format source` there, since browsers run it on their own JS engine.
- **WebGPU warning**: when the browser has WebGPU but `dist-gpu` isn't deployed (or isn't listed in `moduleVersions`), `createJsui()` now logs a console warning naming the fix instead of requesting a device it can't use and quietly rendering on WebGL (#136).
- **Godot on the web** (godot-aw3): the Godot integration builds as a static library for the fork's threaded WebGPU export template (`scripts/build-godot-web.sh`, with Skia Graphite on WebGPU built with pthreads). The demo renders with Graphite on WebGPU in Chrome, with input, the JS thread and the shared HUD working (#135).
- **Vulkan pipeline cache on disk**: Graphite's Vulkan context keeps the driver's `VkPipelineCache` in the user cache directory across launches, validated against the device and driver, so background precompiles stop being full driver compiles every launch (#131).

## Performance

- **docs/PERFORMANCE.md**: where JSUI runs in a game's frame, JS per frame on the demo HUD and showcase screens, native-first vs React state, spikes, memory and disk, engine frame times with and without the UI, and web numbers vs react-native-web (#128, #132).
- **Measuring the UI's cost**: the raylib, sokol, Unity, Unreal and Godot examples take `--no-ui` and `--bench` (`--bench-seconds` in Godot) to time the same game with and without JSUI; the Godot demo's `--hud` runs the shared HUD scene (#129, #130).
- **sokol on Metal**: on macOS the sokol example runs on Metal with Graphite drawing straight into sokol's own texture (UI cost +0.8-1.2 ms on GL down to +0.51 ms). `JSUI_GL_INCREMENTAL` lets a GL host's own texture be the retained frame, so only damage is repainted; raylib uses it (+0.28 to +0.19 ms) (#133).
- The showcase can run on QuickJS for comparison with `?js=quickjs` (#132).

## Fixes

- Release workflow: the npx smoke test waits for every package to appear on npm (#127).

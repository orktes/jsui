JSUI 0.6.0 makes the native libraries about 40% smaller, moves more of the UI off the JS thread (native expressions, composites, animated text and hover / press / focus styles), adds JS debugging in Chrome DevTools and VS Code, and makes navigation smooth with time-sliced renders, idle teardown and a faster QuickJS that collects garbage between frames.

## Highlights

- **JS debugging**: every dev-mode runtime (native viewer, game engines, `--headless`) is a Chrome DevTools / VS Code target through `jsui dev`, with breakpoints on JSX lines via source maps. Runtimes show up in `chrome://inspect`, and the debugger costs nothing while no breakpoint, step or pause is set. Build option `JSUI_DEBUGGER` (off on wasm) (#97, #101).
- **`Animated.derive`**: values computed from Animated values, host data or the frame clock run as native math expressions every frame, with no JS and no frame of lag. `Animated.derive([x, cam], (ux, cx) => clamp((ux - cx) * 0.1, 0, 400))`, `Animated.expr`, `Animated.clock()`, GLSL-style helpers (`clamp`, `lerp`/`mix`, `step`, `smoothstep`, `fract`, `wrap`). `jsui build` keeps the function source for bytecode bundles (#103).
- **Native composites and animated text**: `sequence` / `parallel` / `stagger` / `loop` / `delay` of native-driven steps run as one native animation, so choreography keeps going while JS is busy. The native driver animates layout keys too (`width`, `top`, `flex`, ...), unlike React Native. `<Animated.Text text={Animated.format(node, {decimals, grouping, prefix, suffix})} />` updates numbers without re-renders (#106).
- **State styles without JS**: `hoveredStyle`, `pressedStyle`, `focusedStyle`, `focusVisibleStyle` and `disabledStyle` on any host element, with transitions, plus `group` / `groupHoveredStyle` for descendants and `useInteraction()` for native 0..1 state values (#106).
- **Group state, Visibility and host-state bindings**: `useGroupState()` gives descendants of a `<Group>` / `<Pressable group>` its hover / press / focus as native Animated values. `<Visibility visible={bool | Animated node}>` shows and hides natively, with fade / scale transitions. `useHostStateBind(key, path)` / `Animated.hostState` bind a native value to a field of shared host state, so styles, `Animated.Text`, `derive` and `Visibility` follow game data without a JS tick. Together they make hover popouts and data-driven HUD pieces with no JS (#108).
- **Smooth navigation**: React's scheduler yields on the runtime's per-tick JS budget, so transitions render in slices instead of stalling frames. Set it with `jsui_set_js_frame_budget`, `jsFrameBudget` on the web or `js_frame_budget_ms` in Godot (default 5 ms, 0 turns it off). `onLayout` events reach JS in one batch per tick, and text from sliced renders is shaped in spare frame time before the commit (#98). The old page is torn down in idle slices instead of in the commit frames: frames over 16.7 ms during showcase navigation drop from 5.3 to 3.3 per run (#104).

## Smaller binaries

Skia's desktop, iOS and Android builds now embed the trimmed ICU data set the web and Windows builds already used (everything text shaping and line breaking need, without collation, locales, converters and time zones), the iOS xcframework drops the unused arm64e slice, and every library is linked with dead code stripping (#99). Text renders byte-identically, including Thai, CJK, Arabic, Hebrew and emoji.

## Performance

- **QuickJS engine patches** from react-native-quickjs (inline caches, object literal shape templates, fused opcodes, holey dense arrays, string caches, faster JSON and RegExp) on every build: 8-24% less JS time across jsui-bench (#100).
- **GC between frames**: collections that come due while JS runs are deferred to the end of the tick, so they no longer land in the middle of a commit. The mount scenario's JS p95 drops from 24.0 to 8.4 ms. `jsui_get_perf` reports `gc_*` totals (#100).
- Engine demo HUD: a game-state update re-renders only what changed; a tick with an FPS update goes from 1.09 to 0.40 ms median (#107).

JSUI 0.5.0 is the first release that ships prebuilt native binaries and engine plugins next to the npm packages, and it brings audio, custom fonts, GPU rendering on Windows and Linux, and a large performance round.

## Install

- npm: `npm install @orktes/jsui-react @orktes/jsui-web` and `npm install -D @orktes/jsui-cli`
- Agent skill: `npx @orktes/jsui-cli skill install`
- Unity: Package Manager → Add package from git URL → `https://github.com/orktes/jsui.git#upm` (or `#upm/v0.5.0`), or the `com.orktes.jsui-0.5.0.tgz` below
- Unreal Engine 5: unzip `jsui-unreal-0.5.0.zip` into your project's `Plugins/`
- Godot: unzip `jsui-godot-0.5.0.zip` into your project (`addons/jsui/`)
- C/C++, Rust, Go and other hosts: `jsui-0.5.0-<platform>` archives (shared library, `jsui.h`, CMake package `find_package(jsui)`, `jsui-viewer`); iOS: `jsui-0.5.0-ios-xcframework.zip`

## Highlights

- **Prebuilt binaries on every release**: `libjsui` for Linux x64/arm64, macOS universal and Windows x64, the Godot addon for all of them, and an iOS xcframework (#78).
- **Unity package and Unreal plugin**: `com.orktes.jsui` (JsuiView, native plugin on Metal, Vulkan and D3D) and the `Jsui` UMG widget plugin, both with GPU rendering prebuilt (#75, #80, #81, #90, #92).
- **Engine examples**: raylib, SDL3 (Skia straight into SDL's GPU texture) and sokol hosts of one shared game HUD, with click-to-select units and self-tests through each engine's input path (#67, #76, #77, #92).
- **GPU on Windows and Linux**: Skia m157 on Windows (Ganesh D3D12/D3D11, Graphite Vulkan), Direct3D in Godot, Vulkan/D3D in Unity and Unreal (#82).
- **Audio**: UI sounds and music through a host `on_audio` handler, with a built-in miniaudio default, Web Audio on the web and Godot audio buses; `Sound`, `useSound`, `useMusic`, `UISounds` in React (#69).
- **Custom fonts**: `@font-face` registry, WOFF2/TTC, variable fonts, fallbacks, an expo-font compatible API and host APIs (#68).
- **Shader preloading**: `precompileShaders` / `jsui_precompile_shader` warm GPU pipelines before first use (#70).
- **Rust and Go bindings** over the C API, each with a GPU example app (#83).
- **Android** proof of concept: NDK host on Skia Ganesh GLES (#79).

## Performance

- Native prop diffing, allocation-free native `Animated`, O(changed) damage walk, cached moving shadows (#84).
- Profile-guided QuickJS in the release binaries, faster CPU paint, opt-in React Compiler (#85).
- Precompiled QuickJS bytecode bundles by default in `jsui build` (with a source fallback) (#86).
- Fast damage regions for many moving views: 300 moving markers paint in 2.5 ms instead of 33.5 ms natively (#89).
- QuickJS hot-path patches (Object.keys, for-in, object literals, shape transitions), a React reconciler specialized for the JSUI host config, and a leaner React layer (#93).

## Web

- **The browser's own JS engine is now the default** for `createJsui` (#89, #93). Pass `js: 'quickjs'` to keep running the bundle on QuickJS; pages whose CSP forbids `eval` fall back to QuickJS on their own. The CLI still uses QuickJS by default.
- Opt-in worker mode, `createJsui({ worker: true })`, renders the UI in a Worker on an OffscreenCanvas (#63), with WebKit and context-loss fixes (#71–#74).

## Tools

- Shared live sessions: `jsui dev --shared` and `--attach` let a person and agents drive the same running app, in the viewer, a game, the browser or `--headless` (#62, #65).
- One-command agent skill install (#61).

## Fixes

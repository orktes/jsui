JSUI 0.10.0 brings three React Native libraries to every host: video with react-native-video's `<Video>`, vector drawing with react-native-svg and react-native-skia's `<Canvas>`, and react-native-worklets. It also makes hover frames on the web much cheaper, removes the first-visit pipeline stutter in browsers, and gives the Godot integration an optional UI thread.

## Highlights

- **`<Video>`** (react-native-video's API; `react-native-video` imports resolve to it): a host texture with a player behind it. JSUI still decodes nothing: the new `JsuiConfig.on_video` host interface gets open / set / seek / close commands and reports status back with `jsui_video_status`, the same API on every host. The browser host plays it with an HTML `<video>` (worker mode too) and jsui-viewer on macOS with AVFoundation. JS gets `onLoad`, `onProgress`, `onEnd` and friends, and progress bars can follow the `<texture>.time` host buffer without any JS (#175).
- **react-native-svg and react-native-skia `<Canvas>`** on one native node, VectorView: paths, gradients, clips and masks, runtime effects, filters and path effects drawn with core Skia, parsed once per change. Drawing props animate as paint-only style keys, so Animated values and worklets drive them without React renders. `react-native-svg`, `react-native-svg/css` and `@shopify/react-native-skia` imports resolve to it. Not yet supported: SVG filters, Pattern, Marker, ForeignObject, per-shape touch; Skia Paragraph, Glyphs, Picture, Atlas, Vertices and backdrop filters (#177).
- **react-native-worklets**: `runOnUI`, `runOnJS`, `createWorkletRuntime`, synchronizables and the rest of the API, on separate QuickJS runtimes on the UI thread inside `jsui_tick`. The worklets Babel plugin runs in `jsui build`, `jsui dev` and HMR. An Animated value captured in a worklet is a native handle, so a worklet can set it on the UI thread with no commit (#176).
- **Showcase**: a new `/vector` page with SVG, Skia Canvas and worklet demos (#179); the cinematic screen plays its trailer through `<Video>` (#175). The showcase also runs natively in jsui-viewer, now on Skia Graphite on Metal on macOS, with browser-like trackpad scrolling (#170).
- **Godot UI thread**: `JsuiView.ui_thread` (off by default, lockstep or pipelined) ticks the runtime and records each view's paint on a thread of its own, leaving only the replay to Godot's main thread (#147).

## Performance

- **No first-visit stutter on the web**: the GPU pipelines a page needs are built while it loads, from a shipped list (`createJsui({ pipelines })`) and the lists each browser built before (remembered in IndexedDB); the showcase intro no longer drops to ~13 fps on a cold shader cache (#169).
- **Cheaper hover frames**: text color transitions repaint without rebuilding the paragraph (#146); scaling text draws from a tinted texture of its paint and is repainted exactly once the scale settles (#165); shadow masks are reused while inset shadows scale and panels slide (153 -> 9 masks blurred on the inventory hover sweep, #142); state styles step only the transitions under way (#161); Graphite storage buffers in browsers on Metal / D3D12 (#146).
- **Web idle sleep**: the frame loop stops requesting animation frames when nothing moves and sleeps until the next JS timer or input (`jsui_next_timer`; `idleSleep: false` keeps the old loop) (#143).
- Render targets a host keeps across frames are wrapped once on Dawn and Metal (#137). `jsui-nav --hover-grid` runs the hover benchmark on native hosts (#144).

## Fixes

- iOS Safari no longer pops up the on-screen keyboard when a page comes back (#164).
- Site smoke test waits for the loading splash before screenshots (#174).

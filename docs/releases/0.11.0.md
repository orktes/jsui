JSUI 0.11.0 is a rendering performance release. Native GPU hosts now cache layers and reuse textures for scale and rotation animations, opaque screens stop paying for what they cover, image decoding leaves the frame thread on every platform, and Android moves to Skia Graphite on Vulkan.

## Performance

- **Layer cache on native Graphite** (Vulkan / Metal / Dawn): opacity layers, raster-cached subtrees and motion layers now draw from cached textures on native hosts too, not only on the web. In jsui-viewer on Metal the showcase renders 23–49% faster per frame and issues 25–64% fewer draws, for 4.5–19 MB of cache textures. `JSUI_LAYER_CACHE=off` turns it off (#193).
- **Motion layers**: a cached layer or raster-cached subtree that keeps scaling or rotating is drawn from its texture under the changing matrix and repainted exactly once it rests. `JSUI_MOTION_LAYERS=off` turns it off (#188).
- **Occlusion culling**: the painter skips what later opaque nodes fully cover. A full-screen opaque menu over a busy screen drops from ~2.6 ms to ~0.3 ms of paint; uncovered screens cost the same as before. `JSUI_OCCLUSION=off` turns it off (#185).
- **Image decoding off the frame thread**: large images decode on a worker pool natively (#184) and in browser decode workers on the web (#194). Each frame spends at most ~1 ms of measured time decoding inline; the per-pixel cost estimate is learned at run time (#196).
- **Cheaper damage**: a ringed box (`0 0 0 1px` shadow) no longer repaints its whole interior, which made the inventory's legendary pulse ~2x cheaper (#186); a hover's settling frame no longer switches the raster cache on and repaints the screen (~2 ms per hover, #190).

## Platforms

- **Android on Skia Graphite / Vulkan**, with Ganesh GLES 3 and CPU as fallbacks (`--es jsui_renderer gl|cpu`). On the emulator the launch stall is about halved; the library grows by ~1.2 MB. Real-device numbers are still to come (#195).
- **`jsui_set_cache_dir(dir)`**: new C API that sets where the pipeline, shader and Vulkan driver cache files go (#195).

## Showcase

- Runs in worker mode by default where the worker has WebGPU (`?worker=0` opts out); the page's main thread does 86–95% less work (#191). The `createJsui` library default is unchanged for now.
- Hamburger menu when the nav links don't fit (#189).
